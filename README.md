## About the Project

**Junior Astronaut Mission Trainer** bridges space science and interactive gaming. Players take command of a space outpost where every decision matters. Balancing vital resources like oxygen, power, and radiation shielding teaches children about aerospace engineering constraints in a fun, engaging way.

###  Key Features
* **Resource Management:** Monitor life support, energy grids, and shield integrity in real-time.
* **Real NASA Data Integration:** Dynamic events (such as solar storms) influenced by NASA's APIs (like DONKI).
* **Kid-Friendly UI:** Intuitive dashboard designed specifically for young learners.
* **Zero Backend Friction:** Fast client-side state management for instant gameplay.
